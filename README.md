
# Simple Interest Calculator

## Project Overview

The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount over a specified period at a fixed annual interest rate.

It accepts the principal amount, annual rate of interest, and time period as inputs and calculates the simple interest and total amount.

## Formula

Simple Interest is calculated using the following formula:

Simple Interest = (Principal × Rate × Time) / 100

Total Amount = Principal + Simple Interest

Where:
- Principal: The initial amount of money.
- Rate: The annual rate of interest in percentage.
- Time: The time period in years.

## Features

- Calculates simple interest based on user input.
- Accepts principal, rate of interest, and time period.
- Displays the calculated simple interest.
- Displays the total amount, including interest.
- Simple and easy-to-understand calculation.

## Technology Used

- Bash scripting
- Git
- GitHub

## How to Use

1. Clone or download the repository.
2. Open a terminal in the project directory.
3. Run the calculator script using:

   `bash simple-interest.sh`

4. Enter the principal amount when prompted.
5. Enter the annual rate of interest.
6. Enter the time period in years.
7. View the calculated simple interest and total amount.

## Example

For a principal of 1000, an annual interest rate of 5%, and a time period of 2 years:

- Principal = 1000
- Rate = 5%
- Time = 2 years
- Simple Interest = 100
- Total Amount = 1100
